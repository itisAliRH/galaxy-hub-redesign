Design system sheet · direction M

Tokens and every component of the Mix direction (brand-safe Model 1), with their states, in light and dark. All colour pairs are computed from _build/tokens.py, the same source that writes styles.css.

Colour

Light theme = today's brand tokens unchanged (galaxy-dark, galaxy-primary, galaxy-gold, galaxy-grey and their scales). Dark theme = new role values on an ebony-clay-tinted near-black, with the chrome (top bar, footer, region band) kept galaxy-dark in both themes. Components only use role tokens (--text, --link, --region-bg…), never raw scale values.

Theme switch

System follows prefers-color-scheme; Light/Dark store data-theme on <html> (localStorage hub-proto-theme, try/catch); ?theme=dark|light overrides for one load and is carried on internal links. The choice is applied before the stylesheet paints.

Mobile header and menu sheet

56 px galaxy-dark header: logo · search · context chip · menu (44 px targets). Below it, on pages outside the home region, a “Back to Galaxy Freiburg” bar. The sheet is a full-height modal dialog: context card (“You are in … · Change”), back link, search, the six sections, the contextual nav, then the theme switch; focus trapped, Escape closes, focus returns to Menu, the page behind is inert.
